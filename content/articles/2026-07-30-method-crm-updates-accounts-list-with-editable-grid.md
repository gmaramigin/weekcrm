Method CRM released a set of updates on July 23, 2026, headlined by a redesigned Accounts List that replaces the previous grid with an editable grid and adds quick navigation buttons. The release also includes several bug fixes: card columns in grids built with the new builder now display data correctly, custom views can again be saved after showing or hiding columns, and saving a record with no tag changes no longer adds a blank row to the Audit Trail.
