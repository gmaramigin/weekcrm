Method CRM has released a set of updates addressing bugs and interface improvements across its platform. In the App Builder, input field labels have been moved to a fixed position above the field in every state. The release also includes several bug fixes: an issue where activity comments containing HTML could break the Activities list has been resolved, the Calendar event card button now correctly displays its configured label instead of defaulting to "Edit," and a problem where report generation could hang or fail during heavy load has been fixed. The updates are live for all Method users as of July 28, 2026.
